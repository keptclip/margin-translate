Margin Translate · 页边译

不跳转页面的 Chrome 翻译扩展 · 划词即译 / 页内双语对照 / 多引擎自动降级

一句话说明

本扩展不收集、不存储、不买卖你的任何数据；没有服务器、没有账号、没有埋点、没有广告。

数据流向

只有在下列动作发生时，扩展才会向你自己启用的第三方翻译平台发起请求：

  • 划词翻译（含开启「选中即翻译」后的自动触发）
  • 在面板或工具栏弹窗中点击翻译
  • 开启页内双语对照（此时逐段发送所选区域内容）
  • 在设置页点击某个引擎的「测试连通」（仅发送一小句测试文本）

原文与译文会经过这些平台（MyMemory、Google 免费端点、LibreTranslate、百度翻译、DeepL、微软 Translator，或你自己配置的 OpenAI 兼容网关 / 自建端点），并受其各自隐私政策约束。开发者不接收、不中转、不落库。

使用提醒

请不要用它翻译身份证号、银行卡号、密码、病历、合同正本等敏感内容。若某个站点不希望上传任何文本，请在设置 → 高级 → 站点排除中加入该域名，扩展在该站点将完全停止工作。

关于内置的「Google 免费端点」

该引擎调用的是 translate.googleapis.com 的非官方公开接口，未获 Google 授权，仅供个人学习研究。商业或团队场景请改用 Google Cloud Translation 官方 API，或选择 MyMemory / LibreTranslate / 百度翻译 / DeepL Free / 微软 F0 等官方免费额度。

Short version

Margin Translate collects nothing. No server, no account, no analytics, no ads.

Where your text goes

Requests to third-party providers occur only when you: translate a selection (including the auto-translate-on-selection option), press Translate in the panel or popup, start Inline Bilingual mode, or press "Test connection" for an engine. Destinations are the providers you enabled yourself (MyMemory, Google's public endpoint, LibreTranslate, Baidu Translate, DeepL, Microsoft Translator, or any OpenAI-compatible / self-hosted endpoint you configure). The developer never receives, relays or stores your content.

Permissions

  • storage — local settings, cache, counters.
  • activeTab / scripting — read the current selection only after you click the toolbar icon.
  • contextMenus — right-click translate.
  • commands — Alt+Q / Alt+B / Alt+T shortcuts.
  • alarms — periodic local cache check, no network.
  • http://*/* / https://*/* — inject the in-page selection UI and bilingual mode. No access to chrome:// or the Web Store.
  • Provider hostnames — allow the background worker to call the translation engines you enabled.

Sensitive content

Do not translate ID numbers, bank cards, passwords or medical records. Use Settings → Advanced → Site exclusion to disable the extension on sensitive domains.

Note on the built-in "Google public endpoint"

It calls the unofficial, unauthorized translate.googleapis.com endpoint and is intended for personal study only. For commercial use, switch to the official Google Cloud Translation API or one of the official free tiers listed above.
